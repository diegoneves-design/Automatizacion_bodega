# Pauta de validación · Automatización_Bodega

Este es el guion que lee quien facilita, en este orden. El diseño completo de la prueba está en [docs/prueba-usuarios.md](prueba-usuarios.md). La versión para imprimir, en dos planas, es [pauta-validacion.pdf](pauta-validacion.pdf).

**Dura 20 minutos en total.** Antes de que llegue la persona, el prototipo debe estar abierto en [bodega-prototipo.vercel.app](https://bodega-prototipo.vercel.app), en la primera pantalla, y la planilla lista con su código (P01, P02, P03…). Quien facilita es la única persona que habla con el participante, y **en ningún momento le explica la pantalla**.

## 1. Bienvenida y consentimiento (2 min)

> Gracias por darnos este tiempo. Somos estudiantes de la Universidad de Santiago de Chile y estamos probando un borrador de una herramienta para preparar guías de despacho. De antemano, **no lo evaluamos a usted, sino al borrador.** Si algo no se entiende, es un problema del borrador, no suyo. Si está de acuerdo, vamos a grabar **solo la pantalla y la voz**, no su cara. La grabación sirve para revisar qué partes del borrador cuestan. La ven solo dos integrantes del equipo y la profesora del curso, se guarda en una carpeta privada y se borra al terminar el semestre. No anotamos su nombre, usted será "participante" y un número. Puede saltarse una pregunta o terminar cuando quiera, sin dar explicaciones. **¿Está de acuerdo con que grabemos la pantalla y la voz?**

*(Si dice que "no", no se graba y quien registra anota a mano. La grabación parte solo después del "sí".)*

## 2. Preguntas de contexto (3 min)

1. ¿Cuándo fue la última vez que preparó o revisó una guía de despacho o de retiro? ¿Me cuenta cómo lo hizo, paso a paso?
2. La última vez que le cambiaron un equipo cuando la guía ya estaba casi lista, ¿cómo se enteró? ¿Qué hizo?
3. Esa vez, ¿cómo revisó que los códigos de los equipos estuvieran bien escritos?

*Si hace falta profundizar, solo se pregunta* "¿Y después qué pasó?" *o* "¿Me da un ejemplo de esa vez?"

## 3. Pensar en voz alta (1 min)

> Ahora le voy a pedir que haga dos cosas en este borrador. Mientras lo hace, **vaya diciendo en voz alta lo que piensa**, qué está buscando, qué espera que pase, qué le llama la atención. No hay respuestas buenas ni malas. Mientras lo hace no le voy a poder ayudar, porque justamente queremos ver qué pasa cuando alguien lo usa solo. Al final le respondo todo lo que quiera.

## 4. Tareas (9 min)

Cada escenario se lee una vez, tal cual. Si la persona pide que se lo repitan, se repite (eso no cuenta como ayuda). Si se queda callada, se le pregunta "¿Qué está pensando ahora?". Si lleva más de 2 minutos trabada, se le dice "Si estuviera en su trabajo, ¿qué haría ahora?". Si aun así no avanza, se anota "no completa" y se pasa a la siguiente.

**4.1 Tarea 1 (4 min)**
> Le llegó por correo el pedido de despacho de la Constructora Andes, orden 3001. Antes de armar la guía, revise que todo lo pedido se pueda despachar y déjela lista para pasarla al ERP.

**4.2 Tarea 2 (5 min)**
> Ahora le toca el retiro de la Minera Cordillera, orden 3002. Mantenimiento le confirmó que la extensión que corresponde retirar es la de 63 amperes y 20 metros número 0315. Deje la guía de ese retiro lista para el ERP.

## 5. Cuestionario SUS (3 min)

> Para terminar, le voy a leer diez frases sobre el borrador que acaba de usar. Para cada una, dígame un número del 1 al 5, donde 1 es "muy en desacuerdo" y 5 es "muy de acuerdo".

*(Las frases se leen tal cual y sin explicarlas. Son las del cuestionario SUS, con la redacción adaptada para leerlas en voz alta, en el mismo orden y con el mismo sentido.)*

| N.º | Frase | 1 a 5 |
|---|---|---|
| 1 | Le gustaría usar este sistema con frecuencia. | |
| 2 | El sistema tiene más pasos o cosas de las que hacen falta. | |
| 3 | El sistema le pareció fácil de usar. | |
| 4 | Necesitaría el apoyo de una persona técnica para poder usar este sistema. | |
| 5 | Las distintas funciones del sistema le parecieron bien integradas. | |
| 6 | El sistema le pareció demasiado inconsistente. | |
| 7 | La mayoría de las personas aprendería a usar este sistema muy rápido. | |
| 8 | El sistema le pareció muy engorroso de usar. | |
| 9 | Se sintió muy seguro o segura usando el sistema. | |
| 10 | Necesitó aprender muchas cosas antes de poder usar este sistema. | |

Para calcular el puntaje, a cada frase impar se le resta 1 a la nota y en las pares la nota se le resta a 5. Se suman los diez resultados y el total se multiplica por 2,5 (queda un puntaje de 0 a 100).

## 6. Preguntas de cierre (2 min)

1. En lo que hizo recién, ¿hubo algún momento en que no supo qué hacer? ¿Qué estaba buscando en ese momento?
2. ¿Qué hizo distinto de como lo hace hoy en su trabajo?

*(Quien registra anota si la persona habla, sin que se lo preguntemos, de anotar en papel o de traspasar datos a mano. No se le sugiere ninguna solución.)*

> Eso es todo. Le agradezco mucho el tiempo. ¿Tiene alguna pregunta para nosotros?

*(Recién ahora se pueden responder sus dudas sobre el borrador. Se detiene la grabación, si es que se permitió.)*
